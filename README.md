# 動物病院 評価制度アプリ｜スタッフ向け画面のデモ

動物病院向けの評価制度アプリについて、**スタッフ向け画面の操作イメージ**を確認するためのデモです。
ブラウザだけで動く静的なページで、サーバ側の処理はありません。

公開 URL: https://haruonakachi.github.io/pe-system-demo/

---

## デモ専用であること

- **これはデモであり、本番の仕様ではありません。** 画面構成・集計方法・文言はいずれも検討中のものです。
- ログインはデモ専用の簡易的なものです。
  - メールアドレス: email の形式であれば任意の値
  - パスワード: `password` 固定
- 初期値があらかじめ入力されているので、そのままログインできます。

## データの扱い

- **表示されるデータはすべて架空です。** 氏名・評価・履歴はデモ用に作成した架空のものです。
- **実在するスタッフの情報を入力しないでください。**
- 入力した内容は、開いているブラウザの **localStorage にのみ保存されます**。サーバへは送信しません。
- ブラウザやプロファイルを変えるとデータは引き継がれません。設定画面の「データリセット」でいつでも消せます。

## 評価の構成（A・B・C＋各個人の目標）

評価は次の4つの評価領域で行います。

| 評価領域 | 内容 | レベル |
|---|---|---|
| **A｜基礎・職業人としての力** | ①勤務姿勢・責任 ②コミュニケーション ③主体性 ④セルフ・ストレスマネジメント ⑤学習・成長。全職種共通 | なし（全員が毎回すべてに回答） |
| **B｜（職種ごとの表示名）** | 職種ごとの実践ラダー（必須）とマネジメントラダー（任意）。愛玩動物看護師は「B｜愛玩動物看護実践能力」 | Lv1〜Lv4 |
| **C｜経営・組織に貢献する力** | 経営（①資源・コスト管理 ②時間・生産性 ③サービス価値・経営への理解）と組織（④チームへの貢献 ⑤人材育成 ⑥業務改善）。全職種共通。病院ごとに使う／使わないを選べます | Lv1〜Lv4 |
| **各個人の目標** | 本人と上位職が合意した目標 | なし |

- B と C は、それぞれの**チャレンジレベル1つ分**の実践例に回答します。チャレンジレベルとレベル認定は **B と C で別々**です。
- レベル認定は、対象の実践例すべてに上位2段階（3・4）がつくことで判定します。A と各個人の目標はレベル認定に影響しません。
- 重みの既定値は **A 40％／B 35％／C 15％／各個人の目標 10％**（暫定値）です。C を使わない病院では **A・B・各個人の目標の3つで合計100％** とし、既定値は C の分を除いて残りの比率のまま再正規化した値です（A 約47.1％／B 約41.2％／各個人の目標 約11.8％。集計には正確な比を使います）。
- C③サービス価値・経営への理解の説明文には、本人の職種名が入ります（例：「トリマーの業務やサービスが…」）。
- 問数に上限はありません。評価入力と設定画面に、領域ごとの問数・合計・入力時間の目安（1問あたり30〜60秒）を表示します。

## 画面

- ログイン
- ダッシュボード（B と C の現在のレベルとチャレンジレベル／レベル認定の判定／領域別スコア／重み付き総合スコア／A・B・C のレーダーチャートと、合意した目標ごとの横棒グラフ）
- 評価入力（A → B → C → 各個人の目標 の順に実践例へ回答。1つ回答するごとに自動保存）
- マイページ（合意した目標と適用されている重みの参照を含む）
- 設定
- 評価完了

## 設定画面で切り替えられる項目

- **職種**（愛玩動物看護師／動物ケアスタッフ／トリマー／受付スタッフ。下記）
- **マネジメントラダーの選択**（選択する／選択しない）
- **B のチャレンジレベル**（Lv1〜Lv4）
- **C のチャレンジレベル**（Lv1〜Lv4）
- **各個人の目標**（デモ用の編集。下記）
- **C｜経営・組織に貢献する力（病院の設定・デモ用）**（下記）
- **配色**（比較用。ミント／ブルー／くすみピンク／コーラル）

設定を変えると、回答対象の実践例とダッシュボードの表示がその場で切り替わります。

本人が選ぶ**担当外・観察機会なし**は評価の対象から外れ、平均点の計算にも含まれません。「できていない」とは扱いません。

## 職種の切り替え

設定画面の「職種」で、**愛玩動物看護師／動物ケアスタッフ／トリマー／受付スタッフ**を切り替えられます（既定は愛玩動物看護師）。
本番では職種はアカウントに登録されたものを使います。

- 職種を切り替えると、**B の表示名と、実践ラダー・マネジメントラダーが丸ごと入れ替わります**。
  評価入力とダッシュボードのラダーの見出しには職種名が付き、レーダーチャートの軸はその職種の力になります。

| 職種 | B の表示名 | 実践ラダーの力 |
|---|---|---|
| 愛玩動物看護師 | B｜愛玩動物看護実践能力 | 動物と飼い主を理解する力／動物看護を実践する力／チームで支える力／飼い主と動物の暮らしを支える力 |
| 動物ケアスタッフ | B｜専門実践能力 | 動物と飼い主を理解する力／動物看護を実践する力（診療の補助を含まない）／チームで支える力／飼い主と動物の暮らしを支える力 |
| トリマー | B｜専門実践能力 | 状態を見極める力／施術する力／安全を守る力／飼い主とつなぐ力 |
| 受付スタッフ | B｜専門実践能力 | 受付・案内する力／飼い主に寄り添う力／院内をつなぐ力／正確に処理する力 |

- マネジメントラダーの力（人材育成／チーム運営／改善）は全職種共通で、実践例が職種ごとに変わります。
- **レベル毎の定義（Lv1〜Lv4）・A・C は全職種共通**で、職種を切り替えても変わりません。各個人の目標と重みも変わりません。
- 職種ごとの回答はそれぞれ保存され、切り替えて戻すと元の回答が残っています。
- 保有資格は職種から決まります（資格がないと担当できない実践例を「要資格」として外す仕組みは残しており、どの職種でも現在は0件です）。
- 力・レベル毎の目標・実践例はいずれも**検討中の暫定案（架空）**です。

## C｜経営・組織に貢献する力（病院の設定・デモ用）

本番では、C を使うかどうかと C の実践例は病院内管理者が設定します。デモでは挙動を確認するため、設定画面で編集できます。

- **C を使う／使わない**：使わないにすると、C の回答対象・チャレンジレベル・レベル認定・チャート・領域別スコアの行が消え、重みは A・B・各個人の目標の3つで集計します（C の回答と C を使うときの重みは残り、「使う」に戻すと再び使います）。
- **C の実践例の編集**：項目 × レベルごとに実践例を追加・編集・削除できます。項目（6つ）の名前は編集できません。空欄の実践例は保存できません。
  実践例を削除すると、その実践例への回答も削除します。「既定の実践例に戻す」で既定の24件（暫定案）に戻せます。
- あるレベルの実践例が0件になると、そのレベルを選んだ人には C の回答対象がなくなり、C のレベル認定は「対象なし」になります。

## 各個人の目標

合意した目標は**個数の上限なく**持てます（重点目標は1〜3個が目安です）。設定画面の「各個人の目標（デモ用の編集）」で、次の操作と表示を試せます。

- 合意した目標と実践例の**追加・編集・削除**（実践例が0件の目標は保存できません）
- 「**サンプルの目標を追加**」：経営・人事に関わる目標の例（架空）を1クリックで追加します
- **目標ごとの重み**：目標どうしの比率（％・合計100）で入力し、総合スコアに占める割合を自動で表示します
- **評価領域の重み**：C を使うときは4つ（A／B／C／各個人の目標。既定値 40／35／15／10）、使わないときは3つ（A／B／各個人の目標。既定値 約47.1／41.2／11.8）を、個人ごとに整数で調整できます（合計100）。C を使うときと使わないときの重みは別々に保存され、切り替えても消えません

本番では、合意した目標は本人と上位職の面談で決め、重みは上位職または病院内管理者が設定します。
スタッフは参照のみです。デモでは挙動を確認するため、設定画面で編集できるようにしています。

- 各個人の目標のスコアは、目標ごとのスコア（その目標の実践例の平均）を**目標ごとの重みで加重平均**した値です。
- デモで追加した目標・C の実践例には他者評価の値がないため、他者評価は「—」と表示し、他者評価の計算から外します。
- 合意した目標・重み・C の設定は、データリセットで初期状態に戻ります。

## 以前のバージョンから開いている場合

- 以前の3領域の重み（50／40／10）は、新しい既定値（40／35／15／10）に置き換わります。
- 以前の4領域の重み（A／B／C／各個人の目標）は、「C を使うとき」の重みとして引き継がれます。
- 以前の回答は残ります。以前の「協調性」の回答は C④チームへの貢献の Lv2 の回答として（C のチャレンジレベルを Lv2 にしたときに表示）、「責任感」の回答は A①勤務姿勢・責任の回答として表示されます。

## 説明の開閉

ダッシュボードの長めの説明（レベル認定の判定基準／重みの内訳／各グラフの見方）は、
**既定で閉じています**。見出しをクリックすると開き、開閉した状態はこのブラウザに記憶されます。

「要資格項目・担当外が『できていない』ではないこと」と
「本人評価と他者評価に差があること自体は悪い評価ではないこと」の2つは、
誤解を招きやすいため**常に表示**しています。

外部の CDN・Web フォント・外部 API は使用していません。

```
index.html
css/style.css
js/jobtypes.js  … 職種ごとの B の表示名とラダー（架空のデータ）
js/seed.js      … 架空のシードデータ（A・C・各個人の目標・評価領域と重み）
js/storage.js   … localStorage のラッパ
js/scoring.js   … 集計とレベル認定の判定
js/radar.js     … レーダーチャート（自前の SVG）
js/app.js       … 画面制御
```
