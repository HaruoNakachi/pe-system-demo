# 動物病院 評価制度アプリ｜スタッフ向け画面のデモ

動物病院向けの評価制度アプリについて、**スタッフ向け画面の操作イメージ**を確認するためのデモです。
ブラウザだけで動く静的なページで、サーバ側の処理はありません。

公開 URL: https://haruonakachi.github.io/pe-system-demo/

---

## デモ専用であること

- **これはデモであり、本番の仕様ではありません。** 画面構成・集計方法・文言はいずれも検討中のものです。
- ログインはデモ専用の簡易的なものです。
  - メールアドレス: email の形式であれば任意の値
  - パスワード: `password` 固定
- 初期値があらかじめ入力されているので、そのままログインできます。

## データの扱い

- **表示されるデータはすべて架空です。** 氏名・評価・履歴はデモ用に作成した架空のものです。
- **実在するスタッフの情報を入力しないでください。**
- 入力した内容は、開いているブラウザの **localStorage にのみ保存されます**。サーバへは送信しません。
- ブラウザやプロファイルを変えるとデータは引き継がれません。設定画面の「データリセット」でいつでも消せます。

## 画面

- ログイン
- ダッシュボード（レベル認定の判定／領域別スコア／重み付き総合スコア／面談で確認したいこと／レーダーチャート）
- 評価入力（実践例への回答。1つ回答するごとに自動保存）
- マイページ
- 設定
- 評価完了

## 設定画面で切り替えられる項目

- **マネジメントラダーの選択**（選択する／選択しない）
- **資格の有無**（あり／なし）
- **チャレンジレベル**（レベルⅠ〜Ⅳ）
- **配色**（比較用。ミント／ブルー／くすみピンク／コーラル）

設定を変えると、回答対象の実践例とダッシュボードの表示がその場で切り替わります。

資格を「なし」にすると、資格がないと担当できない実践例は
**要資格（愛玩動物看護師）項目**として評価の対象から外れ、平均点の計算にも含まれません。
本人が選ぶ**担当外・観察機会なし**も同じく計算に含まれません。
どちらも「できていない」とは扱いません。

## 構成

外部の CDN・Web フォント・外部 API は使用していません。

```
index.html
css/style.css
js/seed.js      … 架空のシードデータ
js/storage.js   … localStorage のラッパ
js/scoring.js   … 集計とレベル認定の判定
js/radar.js     … レーダーチャート（自前の SVG）
js/app.js       … 画面制御
```
